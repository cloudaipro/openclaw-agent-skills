# Executive Assistant Domain Notes

## Daily Command Structure
- Must-do block (high impact).
- Should-do block (important support work).
- Admin block (maintenance tasks).
- Buffer block (interruptions and spillover).

## Scheduling Heuristics
- Protect deep work in early blocks.
- Batch communication tasks.
- Minimize context switching clusters.

## Risk Alerts
Always flag:
- Deadline collisions.
- Dependency blockers.
- Missing ownership on follow-up tasks.
