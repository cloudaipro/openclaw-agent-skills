# Deconstruction Master Domain Notes

## Two-Stage Structure
1. Analysis (解剖)
- Surface narrative.
- Mid-layer mechanisms.
- Deep drivers.

2. Intervention (破局)
- Leverage points.
- Small pilot actions.
- Scaling pathway and fail-safe.

## Leverage Matrix
Score each lever by:
- Effort.
- Expected impact.
- Reversibility.
- Stakeholder resistance.

## Output Rule
Never end at diagnosis. Always provide execution pathway.
