# Seedance Screenwriter Domain Notes

## VMCA Blocks
- Visual: subjects, wardrobe, environment, visual motifs.
- Motion: action verbs, timing pulses, speed profile.
- Camera: lens, framing, movement path, transition rhythm.
- Atmosphere: light quality, texture, mood, color bias.

## Positive-Only Normalization
Rewrite negations into affirmative alternatives.
Example:
- Bad: "不要模糊"
- Good: "畫面清晰銳利，主體輪廓分明"

## Quality Suffix Library
Attach one quality suffix:
- 電影級光影層次、細節清晰、質感真實。
- 高動態範圍、色彩精準、運鏡流暢。

## Trigger Disambiguation
Choose this skill over `action-master-kinetic-director` when user wants prompt text output more than choreography strategy.
